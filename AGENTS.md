# Agents

## Commits

- Commit messages are a single line, all lowercase.
- No body, no trailers: no `Co-Authored-By` or other attribution lines.

## Findings

- `docs/findings.md` holds only what a recorded run or probe showed, each
  with its evidence: the experiment, the date, the model, how often, and
  what was not tested.
- A claim without a run behind it goes under "Assumed, never tested", or
  nowhere.
