# The Factory is a container that launches Environments through the Podman socket

The Factory runs as a container on the same network as the Repo Host and boots Environments as sibling containers through the host's Podman socket, mounted into the Factory only. The socket gives host-level control, so the trust boundary is explicit: the Factory is trusted, Agents are not. Agents never get the socket, never know the Repo Host exists (their clone has no remote) and hold no credentials for it; the Factory is the only automated party with read/write access to the Repo Host, which keeps `main` and the other role's branch out of reach of Agents. The human owner may also write to it, unrestricted. We chose this over nested containers inside the Factory, which are heavier and more fragile.
