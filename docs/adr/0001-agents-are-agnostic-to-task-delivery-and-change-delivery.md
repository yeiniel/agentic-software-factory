# Agents are agnostic to Task delivery and change delivery

A Task is a prompt plus a repository, handed to the Agent directly (for example by booting a container with Pi running the prompt, cwd set to a clone of the repo). The same holds in the other direction: the Agent only edits the working tree. It is never instructed to branch, commit or push; the Factory captures the changes from the Environment and does the git work. Agents are never told to go read a Task elsewhere or to publish results, and agent skills are not coupled to either delivery mechanism; both (a git-native issue repo, a file, a CLI, and how branches reach the Integrator) are Factory-side adapters. We chose this as the simplest shape that keeps every algorithmic step outside the agents and leaves delivery open.
